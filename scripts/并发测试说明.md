# 六服务并发测试

脚本直接调用 Mission 和五个下游服务，不通过评测平台的运行创建接口，不写入平台数据库，也不调用平台评分。每个服务各执行题目文件中的 10 道题，最多 5 道同时运行；六个服务同时开始，总计 60 次调用。上游任务可能进一步调用下游，因此下游实际负载可能超过直接提交的 5 个。被测服务自身可能持久化任务或产生文件，本脚本不能控制其内部行为。

测试使用 Node.js 22，在 `backend/` 目录执行。题目见 [concurrency-questions.json](./concurrency-questions.json)，可以复制并修改后通过 `--questions 文件路径` 指定；每个服务必须保留 10 道不同的非空题目。这是固定测试题，不是每日自动随机出题。

## 配置与预检查

方式一：配置现有六个环境变量：`EVALUATION_MISSION_MATERIAL_WS_URL`、`EVALUATION_LITERATURE_WS_URL`、`EVALUATION_AIRCRAFT_LITERATURE_WS_URL`、`EVALUATION_ALLOY_WS_URL`、`EVALUATION_SYNTHESIS_WS_URL`、`EVALUATION_NEW_MATERIAL_WS_URL`。地址仅接受不含账号、密码、查询参数和片段的 `ws://` 或 `wss://` 地址。环境变量可以通过本机未入库的 `.env.local` 提供：

```sh
node --env-file-if-exists=.env.local scripts/concurrency-test.js --dry-run
```

方式二：在 macOS 上，若本机独立评测后端已经运行并配置了这六个地址，可先用 `lsof -nP -iTCP:7716 -sTCP:LISTEN` 查找后端 PID，然后从该进程读取地址；环境变量优先于进程中的地址。脚本不会输出进程中的其他环境变量：

```sh
node scripts/concurrency-test.js --running-backend 后端PID --dry-run
```

预检查只验证配置和题目，不连接服务，也不生成测试报告。

## 启动与查看

去掉 `--dry-run` 即可启动。如果希望退出终端后继续，可以在后端目录运行以下命令，把 `后端PID` 替换为实际数字：

```sh
nohup node scripts/concurrency-test.js --running-backend 后端PID > /tmp/science-concurrency-test.log 2>&1 < /dev/null &
```

默认每道题的客户端超时为 30 分钟，可用 `--timeout-minutes 45` 设置为 1–120 分钟。每个服务在已有任务正常结束后补下一题；如果某题失败或超时，则停止给该服务补发，已开始的任务继续等待，其他服务不受影响。这样避免远端状态未知时盲目追加任务。不自动重试。后台运行要求本机保持运行并有网络连接。

启动日志会给出报告目录，默认位于 `~/science-evaluation-reports/`。`results.json` 在任务启动和完成时更新，包含题目、任务 ID、执行状态和耗时；每条回答和团队输出分别保存在 `tasks/` 下，`results.json` 中的 `detailsFile` 指向对应文件。全部结束后生成 `summary.md`。默认目录仅当前用户可访问，文件权限为 `600`。可用 `--output 新目录路径` 指定一个尚不存在的报告目录。

“完成”只表示收到适配器认可的结束信号并存在输出，不代表答案正确，也不代表稳定并发上限。超时是客户端未在设定时间内收到完整结束，不代表远端任务已取消；本地进程中断时 `results.json` 里的 `running` 表示结果未知。不要直接重跑未知状态的任务。

## Mission 实时连接探针

如果只需对比 Mission 的流式连接，使用 `mission-stream-probe.js`；它复用平台 Mission 适配器，直接建立独立 WebSocket 连接，不经过平台队列或评分。先在 `.env.local` 或环境变量中配置 `EVALUATION_MISSION_MATERIAL_WS_URL`，然后在后端目录运行：

```sh
node --env-file-if-exists=.env.local scripts/mission-stream-probe.js --count 5 --interval-seconds 5
```

用 `--question '题目内容'` 指定题目，`--timeout-minutes 30` 更改等待上限，`--show-text` 显示最近的文字片段（文本中链接会隐藏；终端输出仍可能包含回答内容）。`--help` 列出全部选项。每条连接会显示独立 taskid、总帧/业务帧/文字帧数量、最大帧大小、最近接收时间、最近事件类型和关闭码；心跳不记作业务输出，超过 256 KiB 的帧会单独提示，以便与旧版平台接收上限对照。正常关闭只表示连接按适配器规则结束，不代表答案完整、科学正确或质量合格。

探针不写平台数据库、不调用评委，也不测试平台排队和 SSE；被测服务自身可能保存任务或产生文件。Ctrl+C 或本地超时不代表服务端任务已经取消。
